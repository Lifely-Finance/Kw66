6b. Текст на часы — opcode 0xC5

Реконструировано и уточнено по обратной связи с реального железа: у сообщения есть заголовок id (категория) + len (длина текста в байтах, считается автоматически). id=0x00 на реальных часах показывает экран входящего звонка (иконка сброса, тап гасит экран) — если не хочешь такое поведение, оставляй ненулевой id. Формат в целом ещё не до конца проверен — сообщай, если что-то не так.

8. btsnoop-парсер — что шлёт официальное приложение

Включи «Bluetooth HCI snoop log» в настройках разработчика Android → поработай с часами через GloryFit → вытащи btsnoop_hci.log (или bugreport) → загони файл сюда. Парсер покажет все ATT-записи, соберёт handle→UUID и выделит уникальные команды, которые приложение отправляет часам — включая init-последовательность при коннекте.
