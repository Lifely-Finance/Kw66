# KW66 Lab v3.0

BLE-лаборатория для IMILAB KW66 (протокол GloryFit). PWA, работает офлайн, ставится на домашний экран.

## Что нового в v3

- **Live-пульс**: график E5-потока (~1 Гц), статистика окна 5 мин.
- **Тест восстановления (перетрен)**: падение пульса за 60 с после нагрузки → вердикт.
- **Стресс-монитор v1**: HR>100 три минуты + шаги стоят → дыхательный экран 4-7-8 с живым пульсом.
- **Детектор «вруна»**: базовая линия 10 с → вопрос → измерение пиковой реакции.
- **Фаззер команд**: массовая отправка кандидатов (HR-старт / binding / вибрация) с авторазбором откликов.
  Периодика (A2/F7/B1) фильтруется — показывается только «интересное».
- **btsnoop-парсер**: загрузи `btsnoop_hci.log` (HCI snoop log Android) — парсер вытащит ATT-записи,
  соберёт handle→UUID и покажет уникальные команды, которые официальное приложение шлёт часам.
  Это главный инструмент поиска init-последовательности и команды старта HR.

## Важные протокольные находки (KW66)

1. `E5 00` с телефона **не стартует** замер пульса. Стрим `E5 11 00 XX` идёт только когда замер
   запущен на самих часах. Телефон — пассивный слушатель.
2. Терминатор пустой истории шагов — `B2 FD E0` (не `B2 FD F5`).
3. Артефакт фрагментации: `E5 11 A2 64` — это склейка `E5 11` + `A2 64`, не HR=100. v3 его игнорирует.
4. B1 (realtime steps, 18 байт): шаги предположительно в последних двух байтах BE.
5. Raw-акселерометра и сырого PPG по BLE нет — все фичи строятся на пульсе/шагах.

## Как снять btsnoop

Android: Настройки → Для разработчиков → «Bluetooth HCI snoop log» (вкл) → поработай с часами
через GloryFit (подключение + замер пульса + вибрация из приложения) → выключи лог.
Файл: `/sdcard/btsnoop_hci.log` или через `adb bugreport` (на новых Android snoop лежит внутри bugreport).
Загони файл в раздел 8 приложения.

## Установка

Любой статический хостинг + HTTPS (Web Bluetooth требует secure context).
Или открой index.html через localhost. Добавь на домашний экран — работает офлайн.
