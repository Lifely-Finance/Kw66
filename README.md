# KW66 Touch Recorder v1.0

Экспериментальный PWA для записи входящих BLE D1 событий KW66 без попытки заранее классифицировать их как Morse dot/dash.

## Эксперимент
1. Подключить KW66.
2. Начать запись.
3. Сделать короткий Play/Pause, пауза 3–5 секунд.
4. Сделать длинный Play/Pause, пауза 3–5 секунд.
5. Повторить несколько раз.
6. Аналогично Next и Previous.
7. Стоп → Экспорт JSON.

Приложение не отправляет команды на часы и не запускает Morse decoder.
